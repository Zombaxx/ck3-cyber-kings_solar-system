########################################################################################
# Cyber Kings: Solar System — setting traits
#
# Traits the CK2 character history uses that have no vanilla CK3 equivalent.
# This file only makes them EXIST (so history/characters can carry them over);
# the decisions / interactions / buildings that grant them in play come later.
#
# Groups:
#   1. Cybernetics  — DNI, five levelled implant lines (one per attribute),
#                     arm / leg / skeleton, Cywizard (full conversion), damaged cybernetics
#   2. Origin       — clone, vat-born, cloning defects
#   3. Genetics     — supersoldier (CK2 heavy_worlder), spacer, worlder, GMO, empath, nekojin
#   4. Peoples      — the "fantasy invasion" races under their Cyber Kings names
#
# CK2 -> CK3 key map (also in porting toolkit mappings.py):
#   dni -> dni                       iaei_mk_i..v  -> diplomacy_implant_1..5
#   odin_mk_i..v  -> martial_implant_1..5 (the eye)   pci_mk_i..v   -> stewardship_implant_1..5
#   pluto_mk_i..v -> intrigue_implant_1..5            thoth_mk_i..v -> learning_implant_1..5
#   cybernetic_limb -> cybernetic_arm   cybernetic_leg -> cybernetic_leg   cybernetic_skeleton -> cybernetic_skeleton
#   full_cybernetic_conversion -> full_cybernetic_conversion ("Cywizard")   damaged_cybernetics -> damaged_cybernetics
#   clone -> clone   vat_born -> vat_born   cloning_defects -> cloning_defects
#   heavy_worlder -> supersoldier   spacer_physiology -> spacer   (worlder is new)
#   gmo -> gmo   organic_wifi -> empath   cat_splice -> nekojin
#   elf -> archaic   dark_elf -> elohim   fantasy_dwarf -> neanderthal   dark_dwarf -> jotunn
#   cat_folk -> mau_khet   orc -> denisovan
#
# Number scales are CK3's, not CK2's: health is roughly 1/4 of CK2's (vanilla Herculean = +1.0),
# combat_rating became prowess (vanilla Herculean = +6), fertility is a fraction (-0.5 = -50%).
# All numbers are first-pass placeholders for balancing later.
#
# Icons: gfx/interface/icons/traits/<trait_key>.dds, generated by gen_cyber_gfx.py (CK2 glyphs on CK3-sized backdrops).
########################################################################################
