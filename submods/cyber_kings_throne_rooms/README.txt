Cyber Kings: Solar System - Throne Rooms (submod, split from Visuals WIP 2026-11-15)
===================================================================================
- throne rooms for Earth, Spacer and Cywizard (Archon/Aeon) courts, grandeur 1-3
  (gfx/court_scene, gfx/models/court/rooms/cyber_kings, cyber_kings_court_triggers)
- overrides vanilla gfx/court_scene/scene_cultures/00_default_cultures.txt and grandeur_levels.txt

Location: mod\ck3-cyber-kings_solar-system\submods\<this folder> (inside the main mod, carried by git).
Install on a new PC: copy ck3-cyber-kings_throne-rooms.mod from the submods folder (the folder holding this one) two levels up into Documents\Paradox Interactive\Crusader Kings III\mod\
(its path="mod/ck3-cyber-kings_solar-system/submods/..." is relative, so it works on both PCs), then enable it AFTER "Cyber Kings: Solar System".
Docs and generators: the main mod's _dev\THRONE_ROOMS.md, _dev\scripts\court.
Planet images in the throne-room windows: see the main mod's README credits (Solar System Scope CC BY 4.0, NASA).
