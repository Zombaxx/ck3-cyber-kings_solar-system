Cyber Kings: Solar System - Clothing (submod, split from Visuals WIP 2026-11-15)
==============================================================================
- modern Earth suits, Spacer Guild uniforms, Cywizard robes (cyber_kings_clothes*, cyber_kings_clothing_triggers)
- modern military dress: fatigues + combat helmet, general uniform + peaked cap; no hats/cloaks with modern dress;
  traditional Earth cultures keep vanilla dress (cyber_kings_military*, cyber_kings_military_triggers)
- full overrides of vanilla gene files 05_genes_special_accessories_clothes.txt and 06_genes_special_accessories_headgear.txt

Location: mod\ck3-cyber-kings_solar-system\submods\<this folder> (inside the main mod, carried by git).
Install on a new PC: copy ck3-cyber-kings_clothes.mod from the submods folder (the folder holding this one) two levels up into Documents\Paradox Interactive\Crusader Kings III\mod\
(its path="mod/ck3-cyber-kings_solar-system/submods/..." is relative, so it works on both PCs), then enable it AFTER "Cyber Kings: Solar System".
Docs and generators: the main mod's _dev\CLOTHES.md, _dev\scripts\{clothes,military}.
