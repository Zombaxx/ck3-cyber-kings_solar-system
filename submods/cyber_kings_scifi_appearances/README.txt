Cyber Kings: Solar System - Sci-Fi Culture Appearances (submod, v0.14, 2026-11-14)

Distinct looks for the otherworlden peoples. Load AFTER the main mod (and after Visuals WIP if used).
Install or update: DELETE the old cyber_kings_scifi_appearances folder first, then extract this full zip into mod\.

Birth race is genetic: every character gets a race flag (ck_race_<people>) at game start / creation from its
culture's race tradition, and at birth from its parents (half-bloods: ck_race_half). Looks never change with
culture conversion. Fur pattern, coat, eye colour, Archon sigil, Aeon freckles, orc and Jotnar tones are inherited.

Overrides of vanilla/main-mod files (re-derive after a CK3 patch or when the main mod's eye file changes):
  gfx/models/portraits/male_head/male_head.asset, female_head/female_head.asset   (vanilla + ck ear/snout/brow blendshapes)
  common/genes/02_genes_accessories_misc.txt   (MAIN MOD copy + ck_eyes_* templates)
