Cyber Kings: Solar System - Visuals WIP (submod, 2026-11-12; UI skin only since 2026-11-15)
==========================================================================================
Work-in-progress visuals taken out of the main mod until they are tested:
- sci-fi UI window skin (gfx/interface/skinned, skins/*, component_tiles)

Split off on 2026-11-15 into their own submods (folders next to this one in submods\):
- Clothing      -> cyber_kings_clothes      (launcher ck3-cyber-kings_clothes.mod)
- Throne rooms  -> cyber_kings_throne_rooms (launcher ck3-cyber-kings_throne-rooms.mod)
The main mod keeps the trait icons and the zoomed-out map table (Command Deck + window views).

Location: mod\ck3-cyber-kings_solar-system\submods\<this folder> (inside the main mod, carried by git).
Install on a new PC: copy ck3-cyber-kings_visuals-wip.mod from the submods folder (the folder holding this one) two levels up into Documents\Paradox Interactive\Crusader Kings III\mod\
(its path="mod/ck3-cyber-kings_solar-system/submods/..." is relative, so it works on both PCs), then enable it AFTER "Cyber Kings: Solar System".
Docs and generators: the main mod's _dev\UI_SKIN.md, _dev\scripts\ui_skin.
