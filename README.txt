Cyber Kings: Solar System — CK3 port
=======================================================

What this is
------------
A 1:1 conversion of the CK2 "Cyber Kings: Solar System" map onto Crusader Kings III. 
Every CK2 county became one CK3 county containing one barony (the CK2 capital barony).


Install
-------
1. Copy the folder `ck3-cyber-kings_solar_system` and the file `cyber_kings_solar_system.mod` into
       Documents\Paradox Interactive\Crusader Kings III\mod\
2. Enable the mod in a playset in the launcher.
**(if documents is not on the C drive, update the pathway in the ck3-cyber-kings_solar_system.mod file)
